# JavaScript Assignment

A small interactive JavaScript project built with HTML, CSS, and vanilla JavaScript.

## Features

- Interactive counter with increase, decrease, and reset controls
- Image slider with auto-advance and manual navigation
- Registration form with real-time validation
- JavaScript fundamentals quiz
- Dark mode toggle

## Project Structure

- `index.html` — page layout and sections
- `style.css` — styling and theme support
- `script.js` — interactive JavaScript logic

## Run Locally

Open `index.html` in your browser.

You can also use a local server such as:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```
